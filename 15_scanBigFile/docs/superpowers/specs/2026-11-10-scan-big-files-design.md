# 系统大文件夹（>500M）与大文件（>100M）扫描脚本设计文档

## 1. 目标与背景 (Intent & Goals)
编写一个零外部依赖的 Linux Shell 脚本（`scan_big_files.sh`），用于辅助排查和清理系统磁盘空间，自动搜索系统中所有 **大于 500MB 的文件夹** 和 **大于 100MB 的文件**。

- **核心目标**：
  1. **动态识别并排除外部存储与虚拟文件系统**：不硬编码 `/mnt` 或 `/media`，而是通过 `df -PT`（结合 `lsblk` 可移动设备检测）动态识别外部挂载存储（如 FUSE 挂载的 JuiceFS、rclone/Cloudflare R2、NFS/CIFS 网络存储、USB 移动硬盘等）以及内核虚拟文件系统（`/proc`、`/sys`、`/dev`、`/run` 等），在扫描时自动排除。
  2. **解决父子目录累计体积刷屏问题**：对 `>500MB` 的文件夹进行父子体积扣除去重——若父目录仅因包含已超标（`>500MB`）的子目录而超过 500MB，则只展示最具体的子目录；若父目录扣除超标子目录后自身剩余部分仍 `≥500MB`，则同时保留。
  3. **面向磁盘清理的清晰输出**：分别输出「大于 500MB 的文件夹」与「大于 100MB 的文件」两个部分，均按体积**从大到小降序**排列，并转换为人类可读格式（`MB` / `GB`）。
  4. **灵活扫描范围**：默认扫描根目录 `/`，也支持通过命令行参数指定扫描目录（如 `./scan_big_files.sh /var`）。

- **非目标 (Non-Goals)**：
  - 脚本仅做只读扫描与报告，**不自动删除**任何文件或目录（避免误删系统关键文件）。
  - 不依赖 `ncdu`、`fd`、`dust` 等第三方需额外安装的工具，仅使用 Linux 标准工具链（`df`、`lsblk`、`find`、`du`、`awk`、`sort`）。

## 2. 方案对比与选型 (Approaches)
- **方案 A（已选）：动态 `df` 挂载点探测 + `du`/`awk` 父子体积扣除去重 + `find` 扫大文件**
  - 利用 `df -PT` 动态解析文件系统类型与挂载源，精准识别外部存储与虚拟挂载点。
  - 利用 `du -BM` 采集目录体积后交由 `awk` 扣除已达标子目录体积，消除 `/`、`/home`、`/usr` 等顶层祖先目录刷屏，直达真正占用空间的目录。
  - 利用 `find ... -prune` 高效跳过排除目录，筛选 `-type f -size +100M` 的文件。
- **方案 B：固定层级深度限制（`du --max-depth=N`）**
  - 缺点：层级太浅无法定位具体待清理目录，层级太深仍会父子目录重复刷屏。
- **方案 C：单次 `find` 遍历全盘文件并在 `awk` 中内存累加目录大小**
  - 缺点：处理硬链接重复计数与文件块大小差异较复杂，全盘百万级文件下 `awk` 内存状态维护复杂。

## 3. 详细设计 (Detailed Design)

### 3.1 动态识别外部存储与虚拟文件系统
1. **固定内核伪文件系统兜底**：
   - `/proc`、`/sys`、`/dev`、`/run`（防止 `/proc/kcore` 等虚拟大文件误报及设备节点卡死）。
2. **基于 `df -PT` 动态检测非本地磁盘挂载点**：
   - 解析 `df -PT` 的挂载源（第 1 列 `Filesystem`）、文件系统类型（第 2 列 `Type`）和挂载点（第 7 列 `Mounted on`）：
   - 满足以下任一条件的挂载点（除目标根路径自身外）均判定为外部/虚拟存储并排除：
     - **挂载源非本地块设备**：不以 `/dev/` 开头，或为 `/dev/loop*` 镜像挂载（例如 `JuiceFS:my-r2-jfs`、`remote-storage:banwagong`、`tmpfs`、远程 `host:/path`、`//server/share` 等）。
     - **文件系统类型为外部/网络/虚拟类型**：`fuse*`（如 `fuse.juicefs`、`fuse.rclone`、`fuse.sshfs`、`fuse.s3fs`）、`nfs*`、`cifs`、`smb*`、`tmpfs`、`devtmpfs`、`squashfs`、`overlay`、`iso9660`、`autofs`、`ceph`、`glusterfs`、`9p`、`davfs` 等。
3. **基于 `lsblk` 动态检测 USB / 可移动物理存储（若命令可用）**：
   - 检查 `lsblk -nrpo MOUNTPOINT,RM,TRAN,HOTPLUG`，若块设备标记为可移动（`RM=1`、`HOTPLUG=1`）或总线类型为 `usb`，将其挂载点加入排除列表。
4. **扫描前透明提示**：
   - 在脚本开始扫描前，打印当前识别并排除的虚拟文件系统和外部存储挂载点清单，方便用户核对。

### 3.2 搜索大于 500MB 的文件夹（含父子目录去重）
1. **命令执行**：
   - 为 `du` 构造 `--exclude=<mountpoint>` 参数列表。
   - 执行 `du -BM --exclude=... <target_dir> 2>/dev/null`，先筛选出累计体积 `> 500MB` 的候选目录集合。
2. **父子目录体积扣除去重算法（`awk`）**：
   - 将所有 `> 500MB` 的候选目录按路径深度从深到浅处理。
   - 对于每个候选目录 `D`，计算其**有效自身体积**：
     $$\text{EffectiveSize}(D) = \text{TotalSize}(D) - \sum_{C \in \text{SelectedChildren}(D)} \text{TotalSize}(C)$$
     （其中 $\text{SelectedChildren}(D)$ 是 `D` 下方已经被选入结果集的**最顶层超标子目录**，避免多层嵌套重复扣减）。
   - 若 $\text{EffectiveSize}(D) > 500\text{MB}$（或该目录没有任何 `>500MB` 的子目录），则将 `D` 选入最终输出列表。
   - 输出时展示该目录的总占用体积（转换为可读的 `MB`/`GB`），并按体积从大到小排序。

### 3.3 搜索大于 100MB 的文件
1. **命令执行**：
   - 使用 `find <target_dir>` 配合排除目录的 `-path <mountpoint> -prune -o` 语法，在遍历阶段直接跳过虚拟和外部存储挂载点（不产生无效 I/O）。
   - 筛选条件：`-type f -size +100M`。
   - 获取每个文件的字节/MB 大小与完整路径（优先使用 `find -printf "%s\t%p\n"`，兼容回退 `du -BM` / `stat`），按文件体积从大到小排序并格式化为可读单位（`MB`/`GB`）。

### 3.4 命令行参数与输出格式
- **用法**：`./scan_big_files.sh [扫描目录]`（默认扫描 `/`）。
- **权限与容错**：当以普通用户运行遇到无权限目录时，静默过滤 `Permission denied` 报错并在顶部提示“当前非 root 运行，部分受限系统目录可能被跳过”。
- **输出布局**：
  1. 扫描头部信息（扫描目标路径、自动排除的虚拟目录与外部存储挂载点列表）。
  2. `[1/2] 大于 500MB 的文件夹（按体积降序，已过滤单纯因包含大子目录而超标的父目录）`。
  3. `[2/2] 大于 100MB 的文件（按体积降序）`。
