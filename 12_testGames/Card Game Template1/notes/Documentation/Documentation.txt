This note is high-level documentation for the core parts of this template project.
All events in this project are commented, so you can open any event and read the comments to understand what it does, and how it works.

# Animation Curves

There is 1 Animation Curves witin this project:

ac_card_flip
	Contains curve used within cards draw event to scale their width and height values.



# Fonts

There is 1 font witin this project:

fnt_righteous

# OBJECTS

There are 32 Objects witin this project:

Bases

		User Event 0		Event called when moving cards in and out of the stack.
	
	obj_club_base
		Child object of obj_base_parent for club suit.
		Create				Sets the approprite suit and particle effects.

		Create				Sets the approprite suit and particle effects.
	
Buttons

	obj_3_card_draw

		Left Released		Takes the player into the game.
		
	obj_replay_button
		Button used in menus to replay a game.
		Create				Sets the button sprites.
		
	obj_solve
		Solve button that apears when all the cards are in stacks and can be places when the deck is empty and all cards revealed.

		Step				Updated the state if the option is aready chosen.
		Left Released		Sets the automatic solve flag to true.

Managers
	obj_mouse_manager
		Object that handles moved cards from the mouse.
		Create				Sets up the variables for the card to be saved to as well as declaring a look at function for when cards should be highlighted.
			- update_looking_at()		Function for when card should be highlighted but no card has been selected.
		Step				Moves the grabed card player has selected.
		
	obj_move_and_timer_manager
		Object that handles ingame moves and the timer counters.
		Create				Sets up the timer variables.
			- solve()					Function used when games auto solve flag has been called.
		Update				Updates the timers and checks for win condition.
		End Step			Checks for auto complete condition.
		Draw				draws the HUD information on moves and time.
			
	obj_room_manager
		Handles instances and menus created.
		Create				Sets up global variables and layers.
			- state_paused()			Function called when game is paused to create pause menu.
			- state_unpaused()			Function called when pause menu is destroyed.
			- state_winnner()			Function called when a win screen needs to be created.
			- state_loser()				Function called when lose screen is created.
		Step				Handles pause events as well as toggling fullscreen mode.

Parent Objects
	obj_button_parent
		Parent object for all buttons
		Create				Sets the sprites needed for mouse states as well as selected states.
		Step				Uses mouse coordinated to check and change highlighted state.
		Draw				Draws the button in the correct sprite based on its state.
		
	obj_cards_parent
		Parent object for the base game cards.
		Create				Sets the card properties if can be grabbed and the scale of highlights.
		Step				Checks if the card has been highlighted over by mouse.
		Draw				Draws the card in highlighted mode if needed.
		Left Pressed		Checks for the players mouse to be over and assigns the card as grabbed in the mouse manager.
		
	obj_menu_parent
		Parent object for the splash screen cards.
		Create				Card border setup.
		Draw				Draws card in highlight mode if needed.
		Left Pressed		Exits event.

obj_card
	Card object used for the in game cards created by the deck.
	Create				Defines the card.
		- state_card()				Card lerps position if needed.
		- state_destroy()			Card destroys itself.
	Step				Controls the cards current state.
	Draw				Draws the card at correct face and animated scale if needed.
	Left Released		Checks if conditions of placement are met and will either move or reset card as needed.
		
obj_deck
	Card spawner for the main game.
	Create				Creates the deck of card and sets up functions for handling them.
		- card(_suit, _number)			Constructor used to set up a card.
				_suit					Suit card will be.
				_number					Number card will be.
		- check_for_impossible_game()	Function for checking if a game is impossible.
	Step					Controls what cards are grabbable.
	Draw					Draws the deck when possible.
	Left Pressed			Spawns cards when they exist in deck or resets deck if possible.

obj_zone
	Zones card stacks can attach into to be played.
	Create				Variables the cards scale can be before they will need to adjust.
	Draw				Draws the zones for king placements.
	User Event 0		User event for when card is passed onto the stack.

# Scripts

There are 2 Scripts within this project:

scr_menu_card_swap
	This script is used to swap the main menu cards from the fan out sequence to the displayed interactable card objects.
	
		menu_card_swap()
				This is the function that makes the instance layer with the cards on visible for the main menu.
				
scr_transfer_stack
	This script is used to transfer stacks of cards from one stack to another.
	
		transfer_stack(_stack_previous, _stack_new, _id)
				This is used to transfer stacks of cards from one zone to another.
					
					Parameter			Description
					_stack_previous		Instance id of previous zone cards are coming from.
					_stack_new			Instance id of new zone cards are going to.
					_id					Instance id of card player has selected. (Parent card if in a stack)
